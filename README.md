The method I used to run this simulation in python was to use WINDOWS POWERSHELL.
The required packages to run this file are listed in the list of imports and case calls in lines #1-#6.
If you wish to change the density profile or probe frequency you may do so by directly editing the code on lines #12-#14
To run the program open WINDOWS POWERSHELL and type the command:
">> python "
followed by the filepath (Easiest way to get file path is to drag and drop it directly from the File Explorer)
Then simply hit enter and let the simulation run and it should output the 4 plots
